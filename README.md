# Aphasia-Agentry
Agentic BAS — breach &amp; attack simulation for AI agents and MCP servers. Drives an attacker (curated seed payloads or any LLM via litellm) against a target, proves impact with per-run canaries (not an LLM judge), and reports mapped to the OWASP LLM Top 10 and MITRE ATLAS. Ships a sandbox-inert vulnerable fixture.
